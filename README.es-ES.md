# Método para crackear mybatis plugin 2.x, Markdown Navigator no se ve afectado
**Método de uso:**

1. Coloca el archivo mybatis_plus.jar que deseas crackear en el directorio lib.
2. Modifica las líneas 11 y 12 del código en Crack.java, indicando el plugin a modificar y su versión correspondiente.
3. Ejecuta el método Main de Crack.java.
4. Copia crack_mybatis_plus.jar desde el directorio raíz del proyecto y reemplaza mybatis_plus.jar en el directorio de plugins de IDEA.
5. Reinicia IDEA.

---------------

Crack adicional para Markdown Navigator

1. El nombre del paquete a crackear es idea-multimarkdown/lib/idea-multimarkdown.jar
2. Una vez generado crack_idea-multimarkdown.jar, simplemente reemplázalo.
